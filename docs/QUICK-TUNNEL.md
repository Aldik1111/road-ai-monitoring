# Бесплатная временная ссылка Cloudflare

Запустите `start-share.cmd` в корне проекта или выполните `node share.mjs` в терминале VS Code из папки проекта. Нужен Node.js 24+. При первом запуске скрипт скачивает официальный cloudflared для Windows x64 с GitHub Cloudflare и проверяет SHA256 из метаданных релиза. Установка в систему и аккаунт Cloudflare не нужны.

Скрипт запускает туннель и отдельный экземпляр приложения на 127.0.0.1:3010. Используется существующая база `data/private`. После получения HTTPS-адреса приложение запускается с этим PUBLIC_ORIGIN, Secure-cookie и разными случайными паролями ролей. Прежний демонстрационный пароль заменяется, открытые старые сессии аннулируются. Если был запущен обычный `npm.cmd start`, остановите его перед переходом на общий доступ, чтобы работать только через защищённую внешнюю ссылку.

Ссылка и пароли записываются в `data/private/SHARE-ACCESS.txt`. Все пароли принадлежат владельцу компьютера. Другому человеку передайте ссылку и только пароль его роли. Не передавайте весь файл участникам и не добавляйте его в Git. Случайные пароли сохраняются в `data/private/share-passwords.json` и используются при следующем запуске.

Для остановки запустите `stop-share.cmd` или нажмите Ctrl+C в терминале, где запущен `node share.mjs`. Остановятся и приложение, и туннель. Команда остановки использует уникальный идентификатор сеанса, поэтому не завершает посторонние процессы. Новый запуск создаёт новую ссылку. Компьютер должен оставаться включённым и подключённым к интернету; закрытие ноутбука/сон прерывает доступ. Автозапуск и системные настройки сна скрипт не меняет.

Quick Tunnel предназначен для тестов и демонстрации, без гарантии доступности. Лимит видео в этом режиме — 32 МБ. Данные остаются на вашем компьютере, а запросы посетителей проходят через Cloudflare. Даже после остановки данные в SQLite и файлы сохраняются.

Если порт 3010 занят, не запускайте второй экземпляр. Остановите предыдущий процесс. Для другого порта можно задать `$env:SHARE_PORT='3011'` перед запуском.

Официальная документация: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/
