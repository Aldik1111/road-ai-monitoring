# Запуск и показ / Іске қосу және көрсету

Для доступа по ссылке из интернета см. `HOSTING.md`. Настройки ниже относятся к локальному запуску. После обновления проекта перезапустите сервер (Ctrl+C, затем `npm.cmd start`) и обновите страницу сочетанием Ctrl+F5, чтобы увидеть новую голубую и золотую палитру.

## Windows

Установите Node.js 24+ и перезапустите VS Code после установки, чтобы обновился PATH. Откройте корень репозитория, затем запустите `npm.cmd start` или `node server.mjs`. Откройте http://127.0.0.1:3000. Терминал должен оставаться открытым: вкладку браузера закрывать можно, серверную очередь это не останавливает.

Если порт 3000 занят:

```powershell
$env:PORT = '3001'
npm.cmd start
```

Адрес станет http://127.0.0.1:3001. Сервер намеренно слушает только 127.0.0.1. Для локального показа не нужно открывать порты в брандмауэре.

## Полный сценарий

1. Войдите как **Оператор / Оператор**, пароль `RoadDemo2026!`.
2. Переключите язык сверху. Все системные экраны, статусы, формы и ошибки доступны на русском и казахском.
3. Нажмите **Новая поездка / Жаңа сапар**. Введите маршрут, камеру, локальное время начала и UTC-смещение.
4. Загрузите собственный разрешённый MP4 и GPS CSV. Для короткого показа скачайте пример GPS в форме, укажите **12.10.2026 09:00:00**, **+05:00** и используйте MP4 от 15 секунд. Этот CSV содержит синтетический маршрут, не реальные данные автомобиля.
5. Отметьте согласие **Создать явно тестовые карточки / …тест карточкаларын жасау**. Без отметки сервер честно завершит поездку ошибкой «Детектор не подключён».
6. После загрузки сервер поставит поездку в очередь. Экран обновляется каждые 2 секунды. Быстрая тестовая обработка может завершиться между двумя обновлениями.
7. Откройте **Проверка / Тексеру**. Из пяти синтетических рамок получаются три карточки (для видео длиннее 13 секунд); соседние рамки объединены. Изображение — явно подписанная иллюстрация, а исходное видео доступно отдельно с нужной отметки.
8. Одну карточку отклоните с причиной, другую направьте на обследование. Для третьей при необходимости исправьте широту/долготу с причиной и подтвердите яму. Исходные координаты сохраняются. Повторное подтверждение не создаёт новую заявку.
9. Выйдите и войдите как **Диспетчер / Диспетчер**. В **Карта и задания / Карта және тапсырмалар** откройте ремонт, назначьте исполнителя и срок в будущем.
10. Войдите как **Исполнитель / Орындаушы**. Откройте задание, начните работу, добавьте PNG/JPEG «после», напишите комментарий и отправьте на приёмку.
11. Как диспетчер верните работу с причиной, затем как исполнитель повторно отправьте её на приёмку. Оператор или диспетчер принимает результат и закрывает заявку. Исполнителю закрытие запрещено сервером.
12. Перезапустите сервер и убедитесь, что решения, фото и история сохранились.

Чтобы объединить находку, сначала подтвердите другой кандидат. В ещё не решённой карточке выберите подтверждённый дефект и укажите причину объединения. Ремонтная заявка не дублируется.

Обследование реализовано как отдельная видимая очередь со статусом и причиной. Ремонт до подтверждения не создаётся. Оператор может вернуться к обследованию и подтвердить или отклонить его.

## GPS CSV

```csv
timestamp,lat,lon,accuracy_m
2026-10-12T09:00:00+05:00,44.8480,65.4820,6
2026-10-12T09:00:01+05:00,44.8481,65.4821,6
```

Порядок времени строго возрастающий; каждая дата содержит Z или UTC-смещение. Минимум две точки. Координаты WGS84. Пустая `accuracy_m` означает неизвестную точность. Первая точка должна соответствовать началу видео с допуском 2 секунды. Для полного покрытия нужен трек на всю длительность видео.

Разрыв более 5 секунд, расстояние по времени до ближайшей точки более 2 секунд, неизвестная точность или точность хуже 30 метров дают неопределённое положение. Такая запись остаётся в реестре, но не получает маркер. После ручной правки маркер отображается как приблизительный. GPS описывает положение камеры, а не точную геометрию ямы.

## Данные и резервная копия

По умолчанию `data/private/road.sqlite` содержит сущности, пользователей, сессии и историю; `data/private/files/` — загруженные материалы. Это серверное хранение; localStorage используется только для языка. Папка исключена из Git.

Для резервной копии остановите сервер и скопируйте всю `data/private`. Можно задать иной каталог через `$env:DATA_DIR = 'D:\RoadAI-data'` до запуска.

`DEMO_PASSWORD` задаёт пароль только при первоначальном создании учётных записей в новой базе. Изменение этой переменной не меняет существующие пароли. Управление пользователями и смена пароля не входят в текущий MVP.

## Возможные проблемы

- `node` не найден: установите Node.js 24+ и снова откройте VS Code.
- PowerShell блокирует `npm.ps1`: используйте `npm.cmd start`, как в инструкции.
- Нет карты: проверьте интернет; подложка загружается с OpenStreetMap. Реестр и решения работают независимо от карты.
- Видео не открывается: используйте MP4 с кодеком, поддерживаемым браузером (обычно H.264). Расширение MP4 само по себе не гарантирует поддержку кодека.
- Ошибка GPS: проверьте заголовки, UTC-смещение, порядок точек и начало записи.
- После истечения сессии снова войдите. Продолжительность сессии — 12 часов.

## Қазақша қысқаша

Node.js 24+ орнатыңыз. Жоба бумасын VS Code ішінде ашып, терминалда `npm.cmd start` орындаңыз. Браузерде http://127.0.0.1:3000 ашыңыз. Тіркелгіні таңдап, `RoadDemo2026!` құпиясөзімен кіріңіз. **Жаңа сапар** бөлімінде MP4 пен GPS CSV жүктеп, тест режиміне келісім беріңіз. **Тексеру** бөлімінде ақауды растаңыз. Диспетчер тапсырманы тағайындайды, орындаушы фото мен түсініктеме қосады, оператор немесе диспетчер жөндеуді қабылдайды. Деректер сервердегі SQLite базасында сақталады. Нақты AI детекторы әлі қосылмаған.
