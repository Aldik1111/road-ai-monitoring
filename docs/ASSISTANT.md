# Чат-помощник OpenAI

1. В корне проекта (рядом с package.json) создайте `.env`. Для чата достаточно:

```dotenv
OPENAI_API_KEY=вставьте_свой_ключ
OPENAI_MODEL=gpt-4.1-mini
ASSISTANT_DAILY_LIMIT=50
```

2. Сохраните файл и перезапустите сервер. Для локального запуска: Ctrl+C, затем `npm.cmd start`. Для Quick Tunnel: `npm.cmd run share:stop`, дождитесь остановки, затем `npm.cmd run share`. При перезапуске туннеля интернет-ссылка изменится.
3. Войдите в приложение и откройте «AI-помощник» / «AI-көмекші». Спросите «Как загрузить видео и GPS?» или попросите сводку.

Не копируйте весь `.env.example` для локального запуска: он также содержит настройки хостинга. `.env` загружается сервером автоматически, исключён из Git и не отдаётся браузеру. Переменные окружения хостинга имеют приоритет над файлом. Ключ не нужно отправлять в чат, класть в `public` или `PRIVATE-ACCESS.txt` и давать посетителям. Для отключения платного чата установите `ASSISTANT_DAILY_LIMIT=0` и перезапустите сервер.

## Возможности и данные

Помощник отвечает на русском или казахском согласно переключателю интерфейса. Он объясняет сценарий и получает сводку из SQLite: общие счётчики, по 12 последних поездок, кандидатов и заданий (ID, названия маршрутов, статусы, назначенные роли и сроки). Списки неполные, а счётчики охватывают всю базу. Видео, фото, GPS, пароли, комментарии к заданиям и файлы не отправляются. Вместе с вопросом передаются последние 4 пары сообщений текущей учётной записи.

История сохраняется в SQLite отдельно по учётным записям (последние 20 ответов показаны в интерфейсе). В MVP учётные записи соответствуют ролям: несколько людей под `operator` видят общую историю. API использует `store:false`; это не обещание нулевого хранения со стороны провайдера. Помощник не имеет инструментов для изменения данных. Его ответы нужно проверять. Подключён экспериментальный локальный детектор (DETECTOR.md); тестовые карточки остаются демонстрационными.

## Расходы и ошибки

По умолчанию разрешено 50 попыток в сутки на всё приложение, 5 в минуту на учётную запись и один активный запрос на неё. Сутки считаются по UTC. Лимит хранится в SQLite и не сбрасывается перезапуском. Неудачные обращения к провайдеру тоже расходуют лимит попыток. Вопрос ограничен 2000 символами, ответ — 800 токенами. Автоматических повторов к OpenAI нет. Повтор доставки с тем же Idempotency-Key возвращает сохранённый результат без новой оплаты. После неопределённого исхода перезапуска старый запрос не повторяется автоматически.

Лимит количества запросов — не денежный потолок. Стоимость зависит от модели и объёма текста; расход проверяйте в OpenAI Platform / Usage. Ошибки ключа, квоты, недоступной модели и сети показаны в чате без секретных ответов провайдера. Наличие ключа не подтверждает его действительность; это проверяется первым настоящим запросом.

## Проверка

`npm.cmd test` проверяет чат с подменой ответа провайдера без платных запросов: историю, изоляцию учётных записей, повторную доставку, ограничения, ошибки, фильтрацию контекста и разбор Responses API. Настоящий ответ требует вашего ключа и доступа сервера к api.openai.com.

Документация: https://developers.openai.com/api/docs/guides/text
