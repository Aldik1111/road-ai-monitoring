# AI-мониторинг состояния дорог

MVP для работы дорожной службы: **видео + GPS → предполагаемый дефект → проверка оператором → задание на ремонт → приёмка**.

Проект GTON, задача №4. Интерфейс на **қазақша / русском**, голубая и золотая палитра, серверное хранение данных в SQLite.

## Статус проекта

**Рабочий MVP процесса с экспериментальным AI-детектором.** Загрузка, проверка находок и управление ремонтом реализованы. Локальный инференс подключён, но надёжность распознавания на дорогах не подтверждена.

| Компонент | Что реализовано |
|---|---|
| Видео и GPS | Загрузка MP4 и CSV, проверка входных данных, фоновая очередь и прогресс |
| Детектор | Локальный YOLO11n через ONNX Runtime, выборка 2 кадров/с, рамки и группировка находок |
| Проверка | Подтверждение, отклонение, объединение, направление на обследование, исправление координат |
| Карта | Подтверждённые дефекты с приблизительной GPS-привязкой |
| Ремонт | Назначение исполнителя и срока, выполнение, фото, приёмка или возврат |
| Чат-помощник | OpenAI, русский и казахский, сводка по данным проекта, серверная история |
| Доступ | Четыре ролевые учётные записи; временная HTTPS-ссылка через Cloudflare Quick Tunnel |
| Хранение | SQLite, файлы на сервере, история решений и сохранение данных после перезапуска |

### Ограничения AI

- **Детектор экспериментальный.** На трёх открытых дорожных фрагментах, размеченных автором набора как содержащие ямы, модель не дала находок при текущем пороге. Это выявленные пропуски, а не подтверждение качества.
- Нулевой результат не означает, что дорога без дефектов. Оценка уверенности модели не является измеренной вероятностью. Каждую находку проверяет оператор.
- GPS показывает приблизительное положение камеры. Надёжная точная координата самой ямы не вычисляется.
- Отдельный демонстрационный режим создаёт синтетические карточки с меткой **ТЕСТ**. Они не выдаются за результаты модели.
- Чат умеет объяснять работу приложения и отвечать по сводке. Он не изменяет записи и не анализирует видео. Проверки чата используют подмену ответа OpenAI; настоящий ответ требует действующего ключа и отдельной проверки.

Подробности и источники модели: [детектор](docs/DETECTOR.md). Для рабочего пилота нужны видео вашей камеры, ручная разметка, подбор или дообучение модели и оценка ошибок на отдельном маршруте.

## Быстрый запуск на Windows

Требуется **Node.js 24+**. Python, Docker и отдельная видеокарта не нужны. Для установки зависимостей и скачивания модели нужен интернет.

```powershell
git clone https://github.com/Aldik1111/road-ai-monitoring.git
cd road-ai-monitoring
node --version
npm.cmd ci
npm.cmd run setup:detector
npm.cmd start
```

Если репозиторий уже скачан, откройте его папку в VS Code и начните с `npm.cmd ci`. Команды нужно выполнять **из папки с `package.json`**, иначе npm выдаст ошибку `ENOENT`.

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Оставьте терминал работающим. Остановка — **Ctrl+C**.

После первой установки для следующего запуска достаточно `npm.cmd start`, двойного щелчка по `start.cmd` или конфигурации **Road AI: local server** в VS Code. После обновления кода перезапустите сервер и обновите страницу.

### Учётные записи

В новой локальной базе пароль всех четырёх ролей — `RoadDemo2026!`.

| Учётная запись | Возможности |
|---|---|
| `operator` | Загрузка, проверка находок, исправление координат, решения и приёмка ремонта |
| `dispatcher` | Назначение исполнителя и срока, приёмка и возврат |
| `worker` | Начало назначенной работы, фото и отправка на приёмку |
| `admin` | Действия оператора и диспетчера |

При запуске публичного режима используются отдельные пароли, сохранённые в `data/private/SHARE-ACCESS.txt`. После такого запуска прежний локальный пароль в той же базе больше не действует.

Язык по умолчанию — казахский. Переключатель **Қазақша / Русский** находится сверху; выбор сохраняется в браузере. Пользовательские названия и комментарии автоматически не переводятся.

## Первый сценарий

1. Войдите как оператор и выберите **Новая поездка**.
2. Загрузите MP4 длительностью 2–600 секунд и GPS CSV. Укажите маршрут, камеру, время начала записи и часовой пояс. Формат GPS: `timestamp,lat,lon` и необязательный столбец `accuracy_m`; время должно включать часовой пояс. Пример — [sample-gps.csv](public/sample-gps.csv).
3. Для настоящего инференса **оставьте галочку тестовых карточек выключенной**. Для демонстрации процесса без ожидания реальных находок включите её. Отсутствие модели не переключает обработку в тестовый режим автоматически.
4. Дождитесь результата на странице поездок. Просмотрите кандидатов в очереди проверки: кадр, рамку, время, источник и координаты.
5. Подтвердите подходящую находку — создастся одна заявка. Диспетчер назначит её исполнителю.
6. Исполнитель начнёт работу, добавит фото и комментарий, отправит результат на приёмку. Оператор или диспетчер закроет задание либо вернёт его в работу.

Для прогона сценария нужны собственное видео и соответствующий GPS-трек. Обычный MP4 не считается источником GPS. Нельзя выдавать пример GPS за фактическое место съёмки.

## Доступ через интернет

Для временного показа на Windows:

```powershell
npm.cmd run share
```

Quick Tunnel выдаст HTTPS-ссылку. Адрес и отдельные пароли ролей будут в `data/private/SHARE-ACCESS.txt`. Компьютер, сервер и туннель должны оставаться включёнными. При новом запуске ссылка меняется; постоянный круглосуточный хостинг этим не обеспечивается.

Остановка из другого терминала в папке проекта:

```powershell
npm.cmd run share:stop
```

Также доступны `start-share.cmd` и `stop-share.cmd`. [Инструкция Quick Tunnel](docs/QUICK-TUNNEL.md).

Для будущего размещения подготовлен `render.yaml`. Развёртывание на Render не выполнено; постоянный диск и подходящие ресурсы для детектора нужно настроить отдельно. [Описание хостинга](docs/HOSTING.md).

## Технологии и данные

- Node.js 24, встроенный HTTP-сервер и `node:sqlite`.
- HTML, CSS и JavaScript без отдельной сборки фронтенда.
- ONNX Runtime CPU, sharp и FFmpeg; детектор работает в отдельном процессе, по одной поездке за раз.
- OpenAI Responses API для чата, тайлы OpenStreetMap для карты.

По умолчанию база и загруженные файлы находятся в `data/private/`; путь можно изменить через `DATA_DIR`. Сохраняйте эту папку для резервного копирования при остановленном сервере. Используйте один сервер на одну папку данных.

В Git не должны попадать `.env`, пароли, рабочая база, пользовательские видео и модель. Вес модели скачивается установщиком с проверкой SHA256; версии npm-зависимостей зафиксированы в `package-lock.json`.

## Проверки

```powershell
npm.cmd run check
npm.cmd test
```

На текущей версии с установленной моделью прошли **17 автоматических тестов**: GPS, роли, загрузка, решения, уникальность заявки, цикл ремонта, сохранность данных, чат, локальный инференс, ошибки декодирования и доступность сервера во время обработки.

Тесты используют отдельные временные данные. Без установленной модели две интеграционные проверки детектора пропускаются. Платных обращений к OpenAI тесты не выполняют. Прохождение тестов подтверждает проверенные программные сценарии, **не точность распознавания ям**.
