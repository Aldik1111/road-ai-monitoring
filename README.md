# AI-мониторинг состояния дорог

Обнаружение вероятных ям на записанном видео, проверка оператором, GPS-привязка и задания на устранение.

**Код задачи GTON:** 4. **Статус:** локальный MVP рабочего процесса. Интерфейс на қазақша / русском, серверное хранение SQLite. Реальный детектор пока не подключён; тестовые кандидаты явно обозначены.

## Запуск на Windows

Требуется **Node.js 24 или новее**. Python, Docker и установка npm-зависимостей не нужны.

1. Откройте эту папку в VS Code (в ней находятся `package.json` и `server.mjs`).
2. В терминале выполните:

```powershell
node --version
npm.cmd start
```

3. Откройте http://127.0.0.1:3000 в обычном браузере.

Также можно запустить `start.cmd` двойным щелчком или выбрать конфигурацию **Road AI: local server** и нажать F5 в VS Code. Для остановки — Ctrl+C в терминале.

На экране входа выберите роль. Для локального показа пароль всех четырёх учётных записей — `RoadDemo2026!`:

| Учётная запись | Возможности |
|---|---|
| `operator` | Загрузка, проверка, координаты, решения, приёмка ремонта |
| `dispatcher` | Назначение, срок, приёмка и возврат |
| `worker` | Начало назначенной работы, фото, отправка на приёмку |
| `admin` | Административные действия оператора и диспетчера |

Интерфейс по умолчанию казахский. Переключатель **Қазақша / Русский** расположен сверху; выбор сохраняется в браузере. Введённые пользователем названия и комментарии автоматически не переводятся.

Подробный сценарий: [запуск и демонстрация](docs/RUNNING.md). Устройство и ограничения: [реализация MVP](docs/IMPLEMENTATION.md).

## Доступ через интернет

Бесплатный временный показ: запустите `start-share.cmd` или `npm.cmd run share`. Cloudflare выдаст HTTPS-ссылку, пароли будут в `data/private/SHARE-ACCESS.txt`. Остановка — `stop-share.cmd`. Компьютер должен быть включён. [Инструкция Quick Tunnel](docs/QUICK-TUNNEL.md).

Подготовлен `render.yaml` для Render: один сервер, HTTPS и постоянный диск для SQLite/видео. Само приложение пока не опубликовано. Нужны аккаунт хостинга, актуальный код в GitHub и подтверждение платного сервиса. [Пошаговое размещение и доступ для команды](docs/HOSTING.md).

Дизайн использует голубой и золотой цвета, вдохновлённые флагом Казахстана. В публичном режиме демонстрационный пароль отключён; роли используют отдельные пароли.

## Автоматические проверки

```powershell
npm.cmd run check
npm.cmd test
```

Тесты запускают отдельный сервер с временной базой. Они проверяют GPS, группировку, загрузку, роли, повторные запросы, уникальную заявку, фото, возврат, закрытие и сохранность после перезапуска. Тестовые данные не попадают в рабочую базу.

## С чего начать
1. Прочитать [полное описание и ТЗ](docs/SPECIFICATION.md).
2. Выбрать одну из трёх инструкций ниже.

| Роль в команде | Зона ответственности | Подробная инструкция |

| Участник 1 | Распознавание, группировка и оценка качества | [Задачи участника 1](participants/PARTICIPANT_1.md) |
| Участник 2 | Серверная обработка, GPS и задания | [Задачи участника 2](participants/PARTICIPANT_2.md) |

Номера обозначают обязанности, а не людей. Ролями можно меняться. Имена и личные назначения здесь не фиксируются.

## Организация
Владелец актуальности контракта данных — **Участник 2**. Контракт согласуют все трое.
Ответственный за общий показ — **Участник 3**; каждый демонстрирует и проверяет свою часть.
План предполагает трёх подготовленных участников и доступность необходимых исходных данных. Это оценка объёма одного проекта, не обещание достижения региональных KPI за несколько дней.

## Данные и готовность
Не загружать в Git реальные обращения, персональные сведения, исходные видео, ключи API и пароли. Использовать помеченные тестовые данные и примеры без чувствительных сведений.
Реальный инференс и качество на местных дорогах не подтверждены. Рабочий процесс реализован в демонстрационном режиме; ограничения перечислены в `docs/IMPLEMENTATION.md`.

Источник постановки — таблица задач GTON, предоставленная пользователем, и согласованное в чатах описание. [Страница программы](https://astanahub.com/ru/l/GTON).
